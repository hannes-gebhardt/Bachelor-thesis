# Data Stories for Children and Older Adults: The German Energy Grid as a Case Study

This Repository contains the Data Stories for my bachelor thesis

## How to view the Data Stories

### Older Adults

The Data Story for Older Adults has to be run on a local server in the older adults folder. An easy way to do this is using the live server Extension in Visual Studio Code: install VS Code and add the live server extension, download the older adults folder, open it in VS Code, select the HTML file and click the 'Go Live' button at the bottom right. A browser window should open that displays the Data Story

### Children

To view the Data Story for Children, the HTML file can simply be opened in any browser, no server is neccessary. Make sure that the .js and the .css file are in the same folder as the HTML
